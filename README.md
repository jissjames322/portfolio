# Jiss's Portfolio

Welcome to my personal developer portfolio! This project showcases my skills, experience, and some of the projects I've built, wrapped in a modern interactive design powered by Three.js and GSAP.

## Interactive Terminal (CTF Challenge 🚩)

If you explore the site, you'll find a fully interactive Linux-style terminal embedded in the skills section. 

**Can you solve the CTF?**
I've hidden a Capture The Flag (CTF) challenge directly inside this terminal. You can interact with it using standard bash commands (like `ls`, `cd`, `cat`, etc.). 

Your goal: Find the hidden flag! 

## Tech Stack
- HTML5 / CSS3
- JavaScript (ES6+)
- Three.js (WebGL Shaders)
- GSAP (ScrollTrigger & Animations)

## Local Setup

1. Clone the repository.
2. Open `index.html` in your favorite browser.
3. Explore the site!

Happy hunting!
